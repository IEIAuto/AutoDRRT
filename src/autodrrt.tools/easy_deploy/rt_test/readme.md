# cyclictest 工具简介

### 1. 功能说明
`cyclictest` 是一个用于测试 Linux 系统实时性能的工具，主要测量周期性线程被唤醒时与其预期唤醒时间之间的延迟。它是 PREEMPT-RT 实时内核调试中常用的工具。

---

### 2. 工作原理
- 创建一个或多个周期性线程；
- 每个线程使用实时调度策略（如 `SCHED_FIFO`）；
- 设置周期性定时器；
- 记录每个周期内线程唤醒的实际时间与预期时间的差值；
- 输出每个线程的最小、平均和最大延迟等数据。

---

### 3. 常用命令示例
```bash
sudo cyclictest --smp --priority=99 --interval=1000 --duration=60s
```

参数说明：

| 参数               | 含义                                              |
|--------------------|---------------------------------------------------|
| `--smp`            | 在多个 CPU 上运行多个线程                         |
| `--priority=99`    | 使用 `SCHED_FIFO` 调度策略，优先级设置为 99       |
| `--interval=1000`  | 每 1000 微秒（1ms）唤醒一次线程                   |
| `--duration=60s`   | 测试持续 60 秒                                    |

---

## 测试结果解释

示例输出：

```
T: 0 ( 4850) P:99 I:1000 C:  59997 Min:      2 Act:    7 Avg:    6 Max:     191
T: 4 ( 4854) P:99 I:3000 C:  19298 Min:      2 Act:    4 Avg:  158 Max:    7151
```

各字段含义如下：

| 字段名     | 含义                                            |
|------------|-------------------------------------------------|
| `T:`       | 线程编号                                        |
| `(PID)`    | 线程的进程 ID                                   |
| `P:`       | 优先级                                          |
| `I:`       | 线程唤醒周期（微秒）                            |
| `C:`       | 已完成的周期次数                                |
| `Min:`     | 最小延迟（微秒）                                |
| `Act:`     | 当前周期的延迟                                  |
| `Avg:`     | 平均延迟（微秒）                                |
| `Max:`     | 最大延迟（最重要的指标）                        |

---

## 实时性评估标准

| Max 延迟范围    | 实时性等级 | 说明                                      |
|------------------|-------------|-------------------------------------------|
| < 100 微秒       | 优秀        | 适合高精度工业控制系统                   |
| < 1000 微秒      | 良好        | 满足大多数非关键实时场景需求            |
| 1~5 毫秒         | 一般        | 有待优化，受中断或调度器影响较大        |
| > 5 毫秒         | 较差        | 不适合用于硬实时控制                     |

---

## Jetson优化建议

1. 启用 PREEMPT-RT 实时内核；
2. 使用 `SCHED_FIFO` 或 `SCHED_RR` 实时调度策略；
3. 禁用 CPU 频率调整（`cpu governor`）；
4. 配置 `/dev/cpu_dma_latency` 以避免进入深度睡眠；
5. 使用 `isolcpus`、`nohz_full`、`rcu_nocbs` 等内核启动参数；
6. 固定中断和实时线程的 CPU 亲和性（`taskset`、`irqbalance`）；
7. 禁用非必要服务或硬件（如 GPU、摄像头等）干扰；
8. 使用 `stress` 工具进行压力测试评估系统极限响应能力。
